# Army Pink — Escape Club Discord Server Project

## Project Overview
**Organization**: Army Pink (armypink.org)
**Status**: 501(c)(3) nonprofit, fiscally sponsored by Charity On Top, based in California
**Mission**: Supporting domestic violence survivors through safety-centered transportation (Freedom Rides), concierge support, and wellness resources via their Pathway to Freedom program.

**Volunteer Project**: Build a ready-to-launch private Discord server for the **Escape Club** — a trauma-informed digital community space that complements Army Pink's safe-ride work.

## Deliverables
1. Server structure (categories, channels, roles)
2. Community guidelines
3. Simple onboarding flow
4. Draft templates for wellness prompts and announcements
5. Organized links/resources list

## What We Know
- **Branding**: Pink, off-white, beige tones. Compassionate, action-oriented, professional yet approachable tone.
- **Core Program**: Pathway to Freedom — donation-based Freedom Rides providing immediate safe transportation + optional wellness resources
- **Key Resource**: National Domestic Violence Hotline (800-799-7233 / thehotline.org)
- **Timezone**: Pacific Time (California-based)
